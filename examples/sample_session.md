# 示例对话

一段终端 demo 的真实流程示意（解读内容随你接的模型而变，这里只示意**形状**）。

```
　知命·开源版（zhiming-life）
　────────────────────────────

你 › 看看我的运势

师傅 › 好啊。先报一下你的生辰——出生的年月日和大概的时辰，公历农历都行。

你 › 1990年6月15号下午两点，公历

师傅 ›
你是个外柔内刚的人，待人温和，心里却有自己的一把尺……（先勾人物画像，建立信任）

日主辛金生于午月，火旺当令……（再说盘面客观信号）

古法有云「辛金喜壬水淘洗」……（结合义理联想，但收回本盘）

事业上你适合靠专业立身（把握高）；婚姻大方向平顺，具体时点要再看（把握中）；
中年后或有一次较大的转向（把握低）……

（每条判断都标了把握程度——能信的、只是参考的，一眼分得清）

你 › q
　后会有期。
```

## 这段里发生了什么

1. **supervisor** 第一轮判断「想看综述但缺生辰」→ 追问，不惊动宗师。
2. 第二轮收齐生辰 → 路由到八字，`ready=true`。
3. **core.paipan()** 把 1990-06-15 14:00 排成四柱（确定性，Python 算死）。
4. **bazi_master** 在盘面上分段解读，每条判断标把握程度。

对应代码全在 `zhiming_life/conductor.py` 这一个文件里，几十行看懂。
