# prompts/ —— 这里是结构骨架

prompt 是命理 AI 的关键。这个目录里的 prompt 都是**示例骨架**，给你看清「一份命理
prompt 该长什么形状」，你填入自己的内容就能用。

## 你能从这里学到的「形」

- **supervisor.py** —— 前台 prompt 怎么把「问诊 + 路由 + 状态」三件事说清楚，并用一段
  结构化 JSON 把决策交给编排层。
- **bazi_master.py** —— 解读 prompt 的骨架：身份 + 几条底线 + 结构化分段输出。

这些**结构**是通用的、可学的。你把自己的派别知识、案例、措辞填进这个骨架，就能搭起一个
像样的 agent。

## 一条可以分享的经验

写命理 prompt，我们的体会是：**多投喂知识，少加硬约束**。

> 优先给 agent 更多的背景知识、案例参考、思考维度；尽量少写「必须 X / 不许 Y」。让模型
> 本身的能力发挥出来，别把它管成执行流水线。

只有**输出格式、安全边界、同盘不同命**这几条是硬约束，其余都靠投喂知识引导。碰到一次
不理想的输出，先问「是知识不够还是约束不够」——多半是前者。
