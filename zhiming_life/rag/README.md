# rag/ —— 接口在，自己接语料

让解读「引经据典」靠的是 RAG。这一层给你**接口形状**，语料与检索实现自己接。

## 接口长什么样

`retriever.py` 是一个 stub：师傅解读前会调 `retrieve()` 拿参考资料，默认返回空字符串。
这样系统照样能跑——师傅靠模型自身的命理知识解读，只是少了「引经据典」那一层。想要这一层，
自己准备语料、在 stub 的 TODO 里接上检索即可。

## 一个前提：命例只触发联想，不作判决

引用命例时记着「同盘不同命」：参考多个、每个只取一个最相关的小点，不做整体类比——
别让模型把别人的命整体套到本盘上。
