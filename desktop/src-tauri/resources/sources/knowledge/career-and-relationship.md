# 事业与关系咨询的分析框架

事业问题先区分用户真正要判断的是岗位变化、行业选择、合作关系、收入稳定性，还是行动时机。分析盘面后，应结合用户当前职业、可承受风险和已经发生的事实，给出“保持、试探、切换”一类可执行选项，而不是只给抽象好坏。

关系合看需要分别呈现两位命主的客观盘面，再讨论互动方式。重点观察双方在决策速度、表达方式、边界感和现实压力上的差异。相处建议应落到沟通频率、职责分配、重大决定的确认机制，避免把冲突归结为某一方的固定性格。

当事业调整与伴侣关系同时出现时，应把个人选择和共同生活的影响拆开：先明确不可退让的个人目标，再明确现金流、时间投入与家庭责任，最后约定复盘节点。这样比追求一次性“最优答案”更能降低关系成本。
